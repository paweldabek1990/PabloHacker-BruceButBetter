# Enclosure concepts — PLANNED

No validated CAD, STL or measured enclosure dimensions are present in this repository. The following are design briefs, not manufacturing files.

## A — Rugged

- FDM PETG or ASA, thick protective walls and recessed 2.8-inch display bezel.
- ESP32-S3 N16R8 with access to both USB-C connectors.
- Four physical buttons, 18650 cell, protected charging/power module and space for a regulated supply rail.
- Planned constraints: preserve cable bend radius, antenna clearance, USB connector insertion depth and display active-area visibility.
- CAD status: **PLANNED — dimensions to be measured from the assembled hardware**.
- Indicative BOM: two-part printed shell, M2/M3 inserts and screws, display window/bezel, button caps, 18650 holder, protected charger, regulator, wiring and strain relief.

## D — Open Tech

- FDM PETG/ASA open-frame or skeleton enclosure for bench use and rapid rewiring.
- Same 2.8-inch display, ESP32-S3 dual USB-C, four buttons, 18650, charger/protection and regulator space.
- Planned constraints: probe access, visible pin labels, removable display carrier and no pressure on the breadboard wiring.
- CAD status: **PLANNED — no STL or verified dimensions**.
- Indicative BOM: printed frame, display carrier, button hardware, battery holder, protected charger, regulator and cable ties.

Costs are intentionally not fixed until local suppliers, battery specification and measured clearances are selected.
