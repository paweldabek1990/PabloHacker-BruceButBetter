# Disassembly checklist

- [ ] Save a fresh top-level photo and five close-ups with row numbers visible.
- [ ] Record which USB-C port is used for native USB logging/programming.
- [ ] Disconnect USB and verify LEDs are off.
- [ ] Label both ends of every Dupont wire before removing it.
- [ ] Record the exact breadboard row/column and rail bridge for every end.
- [ ] Photograph the TFT header square-on, with pin labels and connector order visible.
- [ ] Photograph the ESP32 headers square-on, with board labels visible.
- [ ] Record any optional SD/RF/IR modules separately.
- [ ] Do not rely on wire colour alone.
