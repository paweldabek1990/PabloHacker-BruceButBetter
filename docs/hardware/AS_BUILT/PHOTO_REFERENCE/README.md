# AS-BUILT photo reference

The five images in this folder are re-encoded copies of the user-provided photographs. Re-encoding removes camera metadata before publication. The original files are not copied into the repository.

## What the photographs prove

- The assembly contains an ESP32-S3 development board, a red TPM408-2.8 TFT board, and three breadboards.
- The TFT and ESP32 are connected by a large Dupont-wire bundle.
- The photographs do not provide a reliable end-to-end view of every conductor, breadboard row, rail bridge, or TFT header position.

The annotated copies identify only broad regions and uncertainty; they do not assert guessed wire routes.
