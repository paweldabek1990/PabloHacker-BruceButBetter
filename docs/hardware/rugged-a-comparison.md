# Rugged A1 vs A2

| Criterion | A1 touch-only | A2 two buttons |
|---|---|---|
| Parts/cost | lowest | adds two switches, caps and inserts |
| Assembly | simplest | requires button alignment and wiring |
| UI access | touch and stylus | touch plus tactile BACK/SELECT |
| Firmware risk | none | no firmware change requested, but GPIO selection must be verified |
| Recommendation | baseline prototype | optional after mechanical and GPIO audit |

A1 is the recommended first print because the current firmware and touch interface are already working and no new GPIO is needed.
